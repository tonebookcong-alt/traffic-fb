I. MỤC TIÊU
--------------------------------------------------------------------
Tự động hóa 2 luồng bằng PYTHON (đã chốt bỏ n8n):
- LUỒNG A — THU THẬP: cào bài mới từ Facebook nguồn theo KEY → chống trùng
  → AI nhận diện nhân vật/chủ đề → lưu vào Content Pool (Google Sheets).
- LUỒNG B — XUẤT BẢN: 4 khung giờ/ngày → chọn content theo hiệu suất thực
  tế từng Page → rewrite caption (3 bản) → viết bài báo → chỉnh ảnh →
  đăng Web bằng API → gom bộ FB (user TỰ đăng Facebook bằng GPM riêng)
  → xác nhận đã đăng → cập nhật trạng thái.

II. CÁC QUYẾT ĐỊNH ĐÃ CHỐT (không thay đổi nếu chưa hỏi lại user)
--------------------------------------------------------------------
1. Xây hoàn toàn bằng Python — bỏ n8n. Tái sử dụng engine cào cao_fb.py
   (Playwright + trình duyệt thật Edge/Chrome + cookies.txt).
2. Analytics: BỎ Views/Mắt đọc/Reach — chỉ dùng Cảm xúc + Bình luận
   (+ Chia sẻ). Công thức điểm hiện có: diem = likes + cmt*2 + share*3.
3. Đăng Facebook: BỎ GPM — user tự đăng bằng cách riêng. Tool dừng ở khâu
   chuẩn bị bộ bài sẵn sàng (caption + ảnh + link bài báo) + nút xác nhận.
4. AI: user có key API sẵn (sẽ cung cấp hãng + key — điền vào config.json).
5. Website đích: tự code, có API riêng — user sẽ gửi tài liệu endpoint.
6. Sheet: Google Sheets (gspread). CHƯA có credentials → đang chạy chế độ
   Local (thư mục du_lieu_traffic/, mỗi sheet 1 file JSON) — tự chọn động.
7. Nhân vật/chủ đề: KẾT HỢP — danh sách gợi ý khai báo theo KEY trong
   SOURCE CONFIG (cột "Nhân vật gợi ý") + AI được đề xuất tên mới.
8. Mỗi khung giờ đăng 1 bài/slot; khung giờ khai báo theo Page trong
   PAGE CONFIG (cột "Khung giờ đăng").
9. Bootstrap (chưa có analytics): chọn bài MỚI NHẤT đúng KEY.
10. Media giai đoạn đầu: chỉ Ảnh → Ảnh (Pillow). Reels để sau (GĐ4).
11. Báo lỗi: Web UI + log (không Telegram/email).
12. Content quá 7 ngày (content_han_ngay trong config.json) → HET_HAN.

IV. LUỒNG A — THU THẬP (đã code, đang chờ chạy thử)
--------------------------------------------------------------------
1. Đọc SOURCE CONFIG: KEY → Facebook nguồn (+ nhân vật gợi ý).
2. Cào bài mới mỗi nguồn: cao_fb.cào_trang(trang, so_bai=10, so_lan_cuon=3,
   delay=3, cookies từ cookies.txt) — mặc định mỗi 2h (GĐ3 scheduler).
3. Chống trùng: post_id có trong pool → bỏ; caption hash trùng → bỏ.
4. Lưu: caption, media (LINK ảnh FB — KHÔNG tải về máy ở luồng A; tải về
   lúc đăng bài ở GĐ2), link bài, thời gian đăng, likes/comments/shares.
5. AI nhận diện nhân vật/chủ đề (gợi ý + AI thêm mới).
6. Thêm CONTENT POOL: status NEW.

V. LUỒNG B — XUẤT BẢN (GĐ3 — chưa code)
--------------------------------------------------------------------
1. Đến giờ (4 khung giờ/ngày, cột "Khung giờ đăng" trong PAGE CONFIG) →
   lấy Page bật (cột "Bật/Tắt"), 1 bài/slot.
2. Đọc KEY page + tín hiệu nhân vật từ PAGE PERFORMANCE (phan_tich.py).
3. Chọn content (content_pool.chon_content): đúng KEY → nhân vật đang chạy
   tốt nhất → không có thì bài khác cùng KEY (mới nhất trước) → bootstrap
   = bài mới nhất đúng KEY → không có content thì bỏ slot + log.
4. Status: LOCKED → PROCESSING.
5. AI viết lại caption (3 bản, chọn luân phiên) + viết bài báo 1500-1700 từ.
6. Xử lý ảnh (Pillow) theo Format page.
7. Đăng Web: API website (article + media) → Article URL.
8. Status → WEB_POSTED. Tạo bộ FB: caption + ảnh đã xử lý + Article URL
   → thư mục du_lieu_fb/<giờ>/ + hiển thị trên Web UI.
9. USER TỰ đăng Facebook (GPM riêng của user) → bấm "Xác nhận đã đăng FB"
   trên Web UI (hoặc sửa sheet) → FB_POSTED → DONE.
10. Lỗi bất kỳ bước: retry 2 lần → ERROR (không được chọn lại), log + badge.

VI. GOOGLE SHEETS — 4 sheet + cột (schema đã code trong google_sheets.py)
--------------------------------------------------------------------
- PAGE CONFIG:     Page | KEY | Format | Website | Khung giờ đăng | Bật/Tắt
- SOURCE CONFIG:   KEY | Facebook nguồn | Nhân vật gợi ý
- CONTENT POOL:    Content ID | KEY | Nhân vật/chủ đề | Source | Caption |
                   Media | Link bài | Thời gian đăng | Cảm xúc | Bình luận |
                   Chia sẻ | Caption mới | Bài báo | Article URL | Status | Ghi chú
- PAGE PERFORMANCE: Page | Post | KEY | Nhân vật/chủ đề | Cảm xúc | Bình luận |
                   Chia sẻ | Điểm | Thời gian
- Status: NEW → READY → LOCKED → PROCESSING → WEB_POSTED → FB_POSTED
           → DONE / ERROR / HET_HAN

VII. CẦN USER CUNG CẤP (blocking — khi AI khác tiếp tục phải hỏi)
--------------------------------------------------------------------
1. AI: hãng + API key (điền config.json → ai.provider + ai.api_key).
2. API website đích: tài liệu endpoint (đăng article + media, xác thực).
   Khi chưa có → dang_web.py viết giả định, chỉnh sau.
3. Google Sheets: làm theo hướng dẫn `python google_sheets.py --setup`
   (service account + spreadsheet_id) → chuyển sang chế độ Sheets.
4. Dữ liệu khởi tạo: danh sách KEY + nguồn FB + Page đích + Format +
   khung giờ đăng (PAGE CONFIG) — hiện chỉ có 1 dòng test SOURCE CONFIG.
